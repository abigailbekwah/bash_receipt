# Receipt project

A receipt that shows the customers bought,the items, quantity and the prices.

## Problem_Statement​

There is this lady called madam Brigette which sells at Mokolo and prints all her rreceipt with the hands and this made things very difficult. There is need to create a script for her that helps shows the sales, containing her customers information and print it in clean.

## 📌 Project Goals​

- The receipt should contain the customer's informations
- The prices of items and the items bought should be identified

## Tech stack

- Git & github

- Linux Terminal

- Bash script

## Features​

- prompt user for customer name
- Ask for item name, quantity and prices
- Calculate total amount authomatically
- Calculate discount
- Calculate vat /tax
- Generate a formatted receipt in the terminal

## installation and setup

clone the repository

```bash

- cd receipt.sh
- give permission using chmod +x bash-receipt.sh
- run with ./bash-receipt.sh
```
